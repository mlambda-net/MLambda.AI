# L1 — novice

You have never written a rule for a computer to reason with. By the end of this level you will have
stated facts and rules separately, watched a machine work out consequences nobody wrote down, and
seen a proof that those consequences always follow.

| Subject | Page |
|---|---|
| Logic | [logic.md](logic.md) |
| Agents | arriving with `MLambda.AI.Agent` |
| Machine learning | arriving with `MLambda.AI.ML` |
| Reinforcement learning | arriving with `MLambda.AI.Learning` |

At this level a sample uses no notation it has not introduced: `∀`, `⇒` and `∧`, and nothing else.
