# The documentation

The samples are explained at three levels, and every subject appears at each of them.

| Level | Who it is for |
|---|---|
| [L1 novice](L1-novice/) | You have never written a rule for a computer to reason with. |
| [L2 practitioner](L2-practitioner/) | You can read a theory and want to know what the notation buys you. |
| [L3 advanced](L3-advanced/) | You want to prove things about the systems, not only build them. |

Why any of it matters (minds, modal logic, accountability, neuro-symbolic AI) is in
[the ideas](ideas/): four essays that need no code.

First, though: [how Hilbert works](hilbert/). Six short pages, and every sample assumes them.

And after L3: [the actuarial capstone](actuarial/), which is not a fourth level but what the three were
for.

**The levels live here and nowhere else.** No source folder encodes difficulty and no C# declares
it: a page is L1 because it is on the L1 shelf, and a source file is named for its subject so that
someone looking for modal frames finds `Worlds.hs` without knowing which page cites it.
